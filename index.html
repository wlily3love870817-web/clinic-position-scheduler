STEP 1

📄 匯入月班表 PDF（自動辨識）

選擇月班表 PDF，系統會讀取上半部的班表：橫軸為日期、縱軸為人員，每人三列依序代表 早診(1)／午診(2)／晚診(3)。黑字數字＝該診上班；紅字數字＝該診執行行政事項（事項名稱取同格的文字，如週班、績效、會議），例如佳怡 11/9 的「2」是紅字，就是午診做週班；例、休、特、預＝休假／不上班；沒有紅字數字、只有黑字文字（如福科、大里）時，依文字所在列視為該診外出／其他事項。正式人員列中的藍色格子（如福科、大里＝去支援其他院所）會直接略過，不會出現在週班表上。另外，班表下方以藍字標示的其他院所支援人力（如大里來的陳宥芯），其藍色格子內的數字＝該診來支援上班，會自動加入人員清單，一起排入櫃檯、藥局、後場。有行政事項的同仁該診不排入櫃檯、藥局、後場。辨識在你的瀏覽器內完成，檔案不會上傳。

辨識設定（進階）
休假標記 視為一般上班的文字 支援其他院所文字（略過）
以逗號分隔。休假標記的文字不排入任何崗位（班表上的「預」都出現在例休日，預設視為休假）；「視為一般上班」的文字會被當成正常出勤、可排入崗位；其他文字視為行政／其他事項。
尚未匯入。匯入後會自動勾選下方各診別的上班人員與行政事項，仍可手動修改。切換「排班週別」會重新帶入該週資料（手動修改會被覆蓋）。
STEP 1-2

🧩 崗位權限設定（每個人可擔任的崗位）

所有正式人員與當月出現的支援人力，都可以勾選 4 個選項，排班時只會照你勾的來排：
櫃台／藥局／後場：這個人可以被排進哪些崗位，沒勾的崗位絕不會排給他。
行政：這個人可以被放在「備」列做行政／其他事項。當天上班超過 3 人時，多出來的人會優先從有勾「行政」的人裡挑，沒勾行政的人會優先補進崗位。
三個崗位都沒勾（例如稜禎）：只當值班主管或行政，不會排進櫃檯、藥局、後場。設定會存在這個瀏覽器，下次開啟沿用。

STEP 2

👥 確認每個診別可排人員

匯入後會自動勾選。先點上方日期分頁，再點姓名切換上班（藍底＝上班）。分頁上的數字是各診「可排人數」：綠 3 人以上、橘 不足 3 人、灰 無人；+N 代表另有 N 位行政。

📖 排班規則說明
稜禎預設只當值班主管，不會被排到櫃檯、藥局或後場（可在「崗位權限設定」調整每個人可擔任的崗位）。
值班主管依順位自動決定：稜禎 → 欣蓓 → 湞葶 → 佳怡 → 宜姗 → 博鈴 → 韋誠 → 佳愉 → 建凱 → 雅貞。
每診上方可編輯醫師（預設為門診表，可改文字與底色），早診與晚診可勾選鑰匙人員。
有行政事項的同仁以行政為主，不會被排入櫃檯、藥局、後場，也不會被當作值班主管；其餘上班人員則優先補滿三個崗位，多出的人會列在「備」。

STEP 4

📋 本週崗位表

格式比照班表。值班主管依順位自動產生；行政人員不佔用三個崗位，顯示在「備」列。表格內所有人員與事項欄位都可直接點擊修改（臨時換班、請假代班），每診左側的 ＋列／－列 可新增或刪除一列。調整完成後請按「暫存崗位表」，系統會把修改後的崗位計入歷史次數，供下次自動排崗參考。連接 GitHub 後，暫存檔會存到 GitHub 倉庫的「週單紀錄」資料夾。

🐙 儲存到 GitHub

連接後，按「💾 暫存崗位表」會把記錄檔（與本機資料夾版相同的 JSON 內容、相同的檔名規則）存進 GitHub 倉庫的「週單紀錄」資料夾（資料夾不存在時會自動建立），下拉選單也會直接列出 GitHub 上的記錄。
取得 Token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；「Repository access」選 Only select repositories 並只勾這個倉庫；「Permissions → Repository permissions → Contents」選 Read and write。產生後把 Token 貼到下方（直接前往建立）。
Token 只會存在這台電腦的瀏覽器裡，不會寫進網頁程式碼或 GitHub；請勿把 Token 貼進 index.html。公開倉庫裡的人員班表任何人都看得到，建議使用私人倉庫。
